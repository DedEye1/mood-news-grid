# mood-news-grid
Были использованы такие ии как Github Copilot и Deepseek.
Структура и код бэкенда продуманы и написаны вручную, поскольку нет чего-либо, с чем я ещё не сталкивался в этом задании - стандартное жонглирование api. Это позволяет всё точно контролировать, видеть полную картину и не тратить лишние токены.
Чаще всего ии использовались в качестве быстрого поисковика, чтобы освежить какие-либо моменты в памяти, найти источники новостей и бесплатного провайдера api к нейросетям или подправить какие-либо ошибки в коде.
Однако с целью ускорения процесса разработки проекта весь фронтенд был поручен ии.
Не потребовался CORS, поскольку архитектура проекта - монолит.
