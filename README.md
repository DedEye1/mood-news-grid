# mood-news-grid

## Запуск
Перед запуском необходимо установить зависимости и запустить миграции (не касается Docker-версии):
``` bash
npm install
npm run migrate-up
```
- для запуска dev-версии:
``` bash
npm run dev
```
- для запуска собранной версии:
```bash
npm run build
npm start
```
- для запуска в контейнере (при установленном Docker или Docker Desktop) - автоматически устанавливает все зависимости и проводит миграции:
``` bash
docker build -t mood-news-grid .
docker run --name mood-news-grid -p 3001:3000 -v volume:/app/volume mood-news-grid 
```

## Стек
Проект разработан на языке TypeScript с использованием фреймворков Node.js, Next.js и React.

В качестве базы данных используется SQLite, для быстрого администрирования был использован клиент DBeaver.

Проект подготовлен к деплою на сервер - он контейнеризируется благодаря Docker.

## Архитектура проекта
Проект является монолитом, благодаря возможностям Next.js.

### Бэкенд
Бэкенд отвечает:
- за получение ленты rss из источника [Interfax](https://www.interfax.ru/rss), парсинг её xml-формата и сохранение полученных метаданных в базу данных SQLite в таблицу news (столбцы id, title, link, description, category, pubDate);
- за обращение к бесплатному ии-краулеру [Firecrawl](https://api.firecrawl.dev/v2/scrape), который выдаёт информацию со страницы новости в удобном Markdown формате;
- за трансформацию в необходимое настроение через бесплатного провайдера ии-API [HuggingFace](https://huggingface.co/) (ии Llama 3.1) и сохранение в базу данных в таблицу news_content (столбцы id, news_id, content, mood)

Эндпоинты бэкенда располагаются по пути app/api:
- /api/fetch-rss (POST): обновляет список rss (25 новостей) и сохраняет его в базу данных;
- /api/get-all-news (GET): отправляет полный список всех новостей, сохранённых в базу данных;
- /api/get-news-content/[id]/[mood] (GET): сначала получает оригинальное содержимое новости через краулер по указанному id (которое заодно сохраняется в базу данных, если его там ещё нет), потом отправляет нейросети для генерации новости в указанном настроении по параметру mood, сохраняет в базу данных и отправляет эти данные на фронтенд;
- /api/get-news-meta/[id] (GET): отправляет метаданные новости по указанному id из базы данных.

Для ограничения ии-трансформатора, ему были приведены правила (полные правила приведены в [файле](app/_modules/mood-changer.ts) в переменной rules): 
1. Сохрани изначальный формат markdown, обязательно нужно сохранять исходные ссылки.
2. Сохрани ВСЕ имена, даты, числа, места без изменений.
3. Все прямые цитаты (в кавычках) должны быть скопированы ДОСЛОВНО, слово в слово, без изменений.
4. Не добавляй новые факты.
5. Не удаляй существующие факты.
6. Измени только стиль и эмоциональную окраску.
7. Сохраняй цензурность и не допускай радикально политических, расистских и т.п. высказываний.

Однако, скорее всего, из-за низкого качества модели, она может (достаточно редко) продолжать игнорировать эти правила, как бы они ни менялись.

### Фронтенд
Фронтенд отвечает:
- за получение данных в полном объёме, отправляемых из API;
- за представление в виде грида на главной странице всех новостей. В шапке есть кнопка для ручного обновления ленты новостей. Карточка новости содержит метаданные и кнопку "Источник", которая переведёт пользователя на оригинальную страницу новости;

![Главная страница](pictures/Главная%20страница.png)

- за открытие страницы с содержимым новости по нажатию на карточку: в шапке видны метаданные новости, ссылка на оригинальную страницу, кнопку возвращения на главную страницу, а также переключатель настроения новости. Без выбранного настроения на всю страницу будет отображаться оригинальная новость. Если же выбрать какое-либо настроение, то через некоторое время (пока будет создаваться новость через нейросеть в выбранном настроении) оригинальная новость сдвинется влево, а справа появится новость в выбранном настроении. Если убрать настроение, то оригинал вновь займёт всё пространство.

![Страница содержимого новости 1](pictures/Страница%20содержимого%201.png)

![Страница содержимого новости 2](pictures/Страница%20содержимого%202.png)

Эндпоинты фронтенда:
- / - корень, главная страница;
- /news/[id] - страница содержимого новости.

Для парсинга формата Markdown в HTML используется пакет marked. Также использована библиотека компонентов от Google - MaterialUI.

## Комментарии
Проект был сделан в сумме за 2-3 дня, но были проблемы в личной жизни, из-за чего пришлось несколько раз откладывать работу над ним.

Как позже оказалось - можно было не использовать скрейпинг в Markdown, а сразу формировать в HTML и не использовать marked. Хотя считаю, что так получилось даже удобнее, поскольку при разработке поле зрения не засоряется лишними тегами HTML.

Не нашёл инструмента для автоматического построения миграций в SQLite, который есть в Postgresql (пакет pg-migrate), поэтому пришлось создать небольшие аналоги, которые содержатся в директории scripts.

Также хочется отметить, что не потребовался CORS, поскольку архитектура проекта - монолит.

### Что можно добавить:
Можно добавить пагинацию курсор, и обновление ленты с периодичностью раз в n-ное количество времени, но т.к. требуется MVP, то было принято решение не тратить на это лишнее время.

Также можно добавить функционал для расширения доступных режимов настроения.

### Обратная связь по проекту
Проект очень понравился - он достаточно простой и в целом интересный. Ещё не сталкивался с применением ии для трансформации данных и парсинга Markdown в HTML на фронтенде, но остальные технологии были известны.

## ИИ в разработке
При разработке были использованы такие модели как Github Copilot и Deepseek.

Структура и код бэкенда продуманы и написаны вручную, поскольку нет чего-либо, с чем я ещё не сталкивался в этом задании - стандартное жонглирование api. Это позволило всё точно контролировать, видеть полную картину и не тратить лишние токены.

Однако с целью ускорения процесса разработки проекта весь фронтенд был поручен Github Copilot с точным планом того, что я хочу видеть в итоге.

Чаще всего ии использовались в качестве быстрого поисковика, чтобы освежить какие-либо моменты в памяти, найти источники новостей и бесплатного провайдера api к нейросетям или подправить какие-либо ошибки в коде.
